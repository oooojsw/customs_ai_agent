                              第四部分：SDK API 详细规范

一、HTTP API 端点清单
--------------------

1. 健康检查：
   GET /health

2. 会话管理：
   POST   /session              创建会话
   GET    /session              列出会话
   GET    /session/{id}         获取会话
   DELETE /session/{id}         删除会话
   POST   /session/{id}/prompt  发送消息
   GET    /session/{id}/messages 获取消息
   GET    /session/{id}/status  获取状态
   POST   /session/{id}/abort   中止会话

3. 文件操作：
   GET /file/list   列出目录
   GET /file/read   读取文件
   GET /file/status  Git状态

4. 搜索：
   GET /find/text   文本搜索
   GET /find/files  文件搜索

5. 事件订阅：
   GET /event  SSE事件流

二、请求/响应格式
----------------

创建会话请求：
{
  "title": "数据处理会话",
  "directory": "C:/project/root",
  "permission": {
    "allow": ["read", "write", "exec"],
    "deny": ["network", "system"]
  }
}

发送消息请求：
{
  "parts": [{"type": "text", "text": "请分析文件..."}],
  "agent": "default",
  "tools": {"question": false}

                              第五部分：安全问题与解决方案
================================================================================

一、安全风险识别
---------------
1. 路径遍历攻击：尝试访问禁止目录
2. 权限提升：执行危险系统命令
3. 资源耗尽：无限循环或大文件读取
4. 会话泄露：敏感数据未清理

二、安全防护措施
---------------

1. PathGuard（路径守卫）：
   - 白名单目录：data/、config/、temp/、downloads/
   - 黑名单扩展名：.exe、.bat、.cmd、.ps1、.sh
   - 路径规范化：解析 .. 和符号链接

2. 权限配置：
   {
     "allow": ["read", "write", "exec"],
     "deny": ["network", "system", "sudo"]
   }

3. 资源限制：
   - 最大文件大小：100MB
   - 最大执行时间：60秒
   - 最大内存使用：512MB
   - 最大并发会话：5个
