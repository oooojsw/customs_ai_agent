# 14 报关单查询

## 功能定位

报关单查询用于根据平台传入的 `entry_id` 获取一票报关数据，并返回给后续审单、综合审查或报告生成使用。

该能力适合平台已经有业务单号、报关单号或演示单号时使用。

## 推荐 intent

```json
{
  "options": {
    "intent": "declaration_query"
  }
}
```

## 请求示例

```json
{
  "request_id": "req-declaration-query-001",
  "session": {
    "session_id": "session-query-001",
    "user_id": "user-001",
    "tenant_id": "tenant-001"
  },
  "message": {
    "role": "user",
    "content": "查询这票报关数据"
  },
  "business_context": {
    "entry_id": "530120250001",
    "mock_mode": true
  },
  "options": {
    "intent": "declaration_query",
    "response_mode": "stream",
    "include_tool_trace": true,
    "include_structured_result": true
  }
}
```

## 平台展示

```text
tool_started: declaration_query
tool_finished: declaration_query
agent_completed
```

## 最终结果

`GET /api/agent/v1/runs/{run_id}` 中重点读取：

```json
{
  "structured_result": {
    "entry_id": "530120250001",
    "declaration_text": "...",
    "data_source": "mock"
  }
}
```

## 演示建议

该能力一般不单独作为视频重点，而是放在 `full_review` 综合审查链路里展示。

## 当前边界

- 当前真实平台数据接口未正式接入时，会使用 Mock 或 fallback 数据。
- 如果查不到数据，会返回 `DECLARATION_DATA_NOT_FOUND`。
- 如果未传 `business_context.entry_id`，会返回 `DECLARATION_ID_REQUIRED`。
