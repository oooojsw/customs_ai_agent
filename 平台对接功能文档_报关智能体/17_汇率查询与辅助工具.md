# 17 汇率查询与辅助工具

## 功能定位

通用智能体内部包含一些辅助工具，例如汇率查询、金额换算、知识库检索、报告缓冲区读取等。这些不是平台单独对接的接口，但用户在自然语言对话中可能触发。

## 汇率查询

### 功能

根据币种查询汇率，并可进行金额换算。

### 触发方式

用户在 `auto/chat` 中询问：

```text
150000 美元折合人民币是多少？
```

或：

```text
帮我查一下美元兑人民币汇率。
```

### 平台展示

平台只展示：

```text
message_delta
tool_started/tool_finished
```

### 当前边界

- 汇率查询依赖外部汇率服务和网络。
- 外部服务失败时，智能体会返回失败原因。
- 正式报关税款仍应以海关核定汇率为准。

## 知识库检索

### 功能

根据用户问题检索本地法规/知识库片段。

### 推荐正式入口

平台若要固定展示法规检索，建议使用：

```json
{
  "options": {
    "intent": "regulation_search"
  }
}
```

如果是自由聊天，则智能体也可能内部调用知识库检索。

## 报告缓冲区读取

### 功能

当用户先生成报告，再追问报告中某个章节细节时，智能体可读取报告缓冲区回答。

### 触发方式

```text
刚才报告里的法律依据部分是什么？
```

## 平台实现建议

这些辅助工具不需要单独页面。平台只需要统一展示工具调用即可。

## 当前边界

- 辅助工具属于 `auto/chat` 内部能力。
- 不建议平台把这些工具做成独立按钮，除非后续产品明确需要。
