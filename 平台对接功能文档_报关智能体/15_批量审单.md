# 15 批量审单

## 功能定位

批量审单用于接收 Excel/CSV 附件，创建批量审单任务。当前能力处于 degraded 状态，不建议作为首批主演示。

## 推荐 intent

```json
{
  "options": {
    "intent": "batch_audit"
  }
}
```

## 输入方式

平台需要先把 Excel/CSV 上传到平台文件中心，然后在 `attachments` 中传入临时下载 URL。

```json
{
  "request_id": "req-batch-audit-001",
  "session": {
    "session_id": "session-batch-001",
    "user_id": "user-001",
    "tenant_id": "tenant-001"
  },
  "message": {
    "role": "user",
    "content": "创建批量审单任务"
  },
  "attachments": [
    {
      "file_id": "platform-batch-001",
      "kind": "spreadsheet",
      "name": "batch_declarations.xlsx",
      "mime_type": "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet",
      "download_url": "https://platform.example.com/temp/batch_declarations.xlsx"
    }
  ],
  "options": {
    "intent": "batch_audit",
    "response_mode": "stream",
    "include_tool_trace": true,
    "include_structured_result": true
  }
}
```

## 平台展示

```text
tool_started: batch_audit
tool_finished: batch_audit
message_delta: 批量审单任务已创建
agent_completed
```

## 最终结果

```json
{
  "structured_result": {
    "task_id": 123,
    "item_count": 50,
    "status": "queued"
  }
}
```

## 当前边界

- 当前主要是“创建批量任务”，不是完整展示每条审单结果。
- 依赖批量处理相关数据库和服务。
- 平台演示优先级低于智能审单、综合审查、Mock 报关全链路。
- 附件域名仍需配置 `AGENT_V1_ATTACHMENT_ALLOWED_HOSTS`。
