# 19 健康检查与能力发现

## 功能定位

平台可以通过健康检查和能力发现接口确认智能体服务是否可用，以及当前支持哪些能力。

## 能力发现

```http
GET /api/agent/v1/capabilities
```

返回示例：

```json
{
  "agent_name": "customs_agent",
  "display_name": "报关智能体",
  "schema_version": "1.0",
  "capabilities": [
    {
      "name": "customs_chat",
      "description": "报关咨询、多轮对话及现有 Agent 工具编排",
      "status": "available",
      "input_kinds": ["text"],
      "output_kinds": ["text", "structured_data"]
    }
  ]
}
```

## 当前 capabilities 名称

```text
customs_chat
declaration_audit
image_ocr
compliance_report
full_customs_review
mock_import_declaration
batch_audit
table_image_to_xlsx
declaration_template_fill
```

## 健康检查

```http
GET /api/agent/v1/health
```

返回示例：

```json
{
  "status": "ok",
  "schema_version": "1.0",
  "service": "customs-agent-v1",
  "dependencies": {
    "chat_agent": "ready",
    "knowledge_base": "ready",
    "reporter": "ready",
    "ocr": "configured",
    "file_center": "local_fallback",
    "run_store": "SQLiteRunStore"
  }
}
```

## 平台使用建议

平台启动或进入智能体页面时：

```text
1. 调 health 判断服务是否在线。
2. 调 capabilities 获取能力列表。
3. 根据 capabilities 决定是否展示 OCR、批量审单等入口。
```

## 当前边界

- `status=ok` 表示主服务可用，不代表每个外部依赖都百分百可用。
- `image_ocr` 如果附件域名未配置，可能显示 degraded。
- `file_center=local_fallback` 表示暂时使用智能体临时文件托管。
