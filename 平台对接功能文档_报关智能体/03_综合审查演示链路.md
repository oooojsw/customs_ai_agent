# 03 综合审查演示链路

## 功能定位

综合审查演示链路用于展示平台调用一个智能体任务后，自动完成报关数据获取/输入、审单、法规依据整理、报告生成。

这是一个适合录视频的稳定演示入口。

## 推荐 intent

```json
{
  "options": {
    "intent": "full_review"
  }
}
```

## 请求示例：使用演示报关单号

```json
{
  "request_id": "req-full-review-001",
  "session": {
    "session_id": "session-full-review-001",
    "user_id": "user-001",
    "tenant_id": "tenant-001"
  },
  "message": {
    "content": "对这票报关单做完整审查并生成报告"
  },
  "business_context": {
    "entry_id": "530120250001",
    "mock_mode": true
  },
  "options": {
    "intent": "full_review",
    "response_mode": "stream",
    "include_tool_trace": true,
    "include_structured_result": true,
    "output_file_policy": "agent_temporary",
    "timeout_seconds": 600
  }
}
```

## 请求示例：直接传文本

```json
{
  "request_id": "req-full-review-002",
  "session": {
    "session_id": "session-full-review-002",
    "user_id": "user-001",
    "tenant_id": "tenant-001"
  },
  "message": {
    "content": "请审查并生成报告"
  },
  "business_context": {
    "declaration_text": "货物名称：32位数字信号处理器\nHS编码：85423100\n数量：5000 个\n单价：15 USD\n总价：75000 USD\n原产国：马来西亚"
  },
  "options": {
    "intent": "full_review",
    "output_file_policy": "agent_temporary"
  }
}
```

## 平台展示

重点展示：

```text
tool_started/tool_finished: 查询报关单、执行审单、整理法规依据、生成报告
output_created: 法规引用、DOCX 报告
message_delta: 最终总结
agent_completed: 完成
```

## Output

可能产生：

```text
citation_set：法规依据
document/docx：审查报告
structured_data：审单结果
```

平台通过 `output_created.data.output.agent_output_url` 下载报告。

## 演示建议

视频脚本：

1. 平台输入报关单号或报关文本。
2. 智能体显示“查询演示报关单”。
3. 智能体显示“执行演示审单”。
4. 智能体显示“整理法规依据”。
5. 智能体生成 DOCX 报告。
6. 平台点击下载报告。

## 当前边界

- `AGENT_V1_DEMO_MODE=true` 时走演示链路，结果稳定，适合录屏。
- 真实业务系统查询、真实法规接口、真实文件中心需要平台提供正式接口后再联调。
