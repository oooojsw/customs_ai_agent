# 12 功能模块总览表

该表用于让平台侧快速理解报关智能体当前有哪些能力、每个能力应该怎么接入、是否适合演示。

## 能力总览

| 模块 | intent | 当前状态 | 输入 | 输出 | 是否建议演示 |
| --- | --- | --- | --- | --- | --- |
| 通用智能体对话 | `auto` / `chat` | 可用 | 用户自然语言 | 文本、工具事件、子智能体事件 | 建议 |
| 智能审单 | `audit` | 可用 | 报关文本或结构化上下文 | 风险结论、findings | 强烈建议 |
| 综合审查演示链路 | `full_review` | 可用，演示模式稳定 | entry_id 或 declaration_text | 审单、法规、报告 | 强烈建议 |
| Mock 报关全链路 | `mock_import_declaration` | 可用，流程最完整 | mock_case_id 或自定义 declaration | 流程进度、海关回复、归档 | 强烈建议 |
| 法规检索 | `regulation_search` | 可用 | 查询文本 | citation_set、文本总结 | 建议 |
| 合规报告生成 | `report` | 可用 | report_source | DOCX、文本总结 | 建议 |
| 报关单查询 | `declaration_query` | 可用，真实数据接口未正式接入时使用 Mock/fallback | entry_id | declaration_text、data_source | 作为组合流程展示 |
| 图片 OCR | `ocr` | 可用但依赖外部 OCR 服务 | image attachment | structured_data、可选 xlsx | 谨慎演示 |
| PDF 识别 | `ocr` + document attachment | 协议预留，未稳定验收 | PDF attachment | 理论上走 OCR 后端 | 不建议承诺 |
| 批量审单 | `batch_audit` | degraded，占位能力 | spreadsheet attachment | 任务占位/结构化结果 | 不建议主演示 |
| 表格图转 Excel | 能力描述存在 | degraded，待多模态负责人完善 | image/document | structured_data、xlsx、image | 后续演示 |
| 报关单模板填写 | 能力描述存在 | planned | structured_data + template | xlsx/pdf/png | 后续演示 |
| HS 编码辅助 | `auto/chat` 内部 Skill | 可用 | 商品描述 | HS 建议、依据、风险 | 可选 |
| 税费估算 | `auto/chat` 内部 Skill | 可用 | CIF、HS、原产国 | 关税、增值税、总税额 | 可选 |
| 汇率查询 | `auto/chat` 内部工具 | 可用但依赖外部汇率服务 | 币种、金额 | 汇率和换算结果 | 可选 |
| OpenCode 子智能体 | `auto/chat` 内部工具 | 可用，偏工程任务 | 复杂本地任务 | subagent 事件、文件 Output | 不建议业务主演示 |
| 健康检查 | `GET /health` | 可用 | 无 | 服务依赖状态 | 平台启动检查 |
| 能力发现 | `GET /capabilities` | 可用 | 无 | capabilities 列表 | 平台入口控制 |

## 平台最小展示能力

平台侧最少需要做：

```text
1. 文本输入框
2. 创建 Run
3. SSE 消费
4. 聊天气泡显示 message_delta
5. 工具调用列表显示 tool_started/tool_finished
6. 流程进度条显示 customs_process_updated
7. 文件卡片显示 output_created
8. 停止按钮调用 cancel
```

## 最推荐的 4 个首批演示

| 顺序 | 演示 | 推荐原因 |
| --- | --- | --- |
| 1 | 平台统一入口 + 通用问答 | 证明已经集成到平台 |
| 2 | 智能审单 | 业务价值最直观 |
| 3 | Mock 报关全链路 | 流程最完整，适合视频 |
| 4 | 报告下载 | 展示文件产出 |

如果多模态负责人准备好了样例图，再加入：

```text
图片 OCR -> 结构化 JSON -> 表格 Excel
```

## 不建议平台现在重点演示的内容

```text
PDF 识别
真实海关提交
真实平台文件中心上传
批量审单全自动完成
填写后报关单图片/PDF 生成
OpenCode 子智能体作为业务功能单独展示
```

原因是这些当前属于预留或后续扩展，不适合在第一次平台视频里承诺。

## 功能边界说明

平台对外宣传时建议使用：

```text
报关智能体提供演示级智能审单、法规辅助、报告生成、Mock 报关全链路和多模态接口预留能力。
```

不建议说：

```text
已经接入真实海关系统
PDF 稳定识别
表格识别百分百准确
自动完成真实申报
```
