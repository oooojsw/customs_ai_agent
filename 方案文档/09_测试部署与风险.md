## 13. 测试方案

### 13.1 单元测试

```python
# tests/test_opencode_client.py

import pytest
import asyncio
from src.services.opencode_client import OpenCodeClient


@pytest.fixture
async def client():
    c = OpenCodeClient(base_url="http://127.0.0.1:4096")
    yield c
    await c.close()


@pytest.mark.asyncio
async def test_health_check(client):
    result = await client.health_check()
    assert result["healthy"] is True


@pytest.mark.asyncio
async def test_create_session(client):
    result = await client.create_session(workspace_dir="data", title="测试会话")
    assert "id" in result
    assert result["title"] == "测试会话"


@pytest.mark.asyncio
async def test_send_message(client):
    session = await client.create_session(workspace_dir="data")
    result = await client.send_message(
        session_id=session["id"],
        parts=[{"type": "text", "text": "列出当前目录"}]
    )
    assert "info" in result or "parts" in result


@pytest.mark.asyncio
async def test_read_file(client):
    result = await client.read_file("data/mcp_servers.json")
    assert "content" in result


@pytest.mark.asyncio
async def test_search_files(client):
    result = await client.search_files("config")
    assert isinstance(result, list)


@pytest.mark.asyncio
async def test_list_files(client):
    result = await client.list_files("data")
    assert isinstance(result, list)
    assert len(result) > 0
```

### 13.2 集成测试

```python
# tests/test_opencode_integration.py

import pytest
from src.services.opencode_client import OpenCodeClient
from src.services.opencode_tools import OpenCodeTools


@pytest.fixture
async def setup():
    client = OpenCodeClient(base_url="http://127.0.0.1:4096")
    tools = OpenCodeTools(client)
    yield client, tools
    await client.close()


@pytest.mark.asyncio
async def test_tool_create_session(setup):
    client, tools = setup
    result = await tools.tools[0].coroutine("data|测试会话")
    assert "success" in result
    import json
    data = json.loads(result)
    assert data["success"] is True
    assert "session_id" in data


@pytest.mark.asyncio
async def test_full_workflow(setup):
    client, tools = setup
    # 1. 创建会话
    session = await client.create_session(workspace_dir="data")
    assert "id" in session

    # 2. 发送消息
    result = await client.send_message(
        session_id=session["id"],
        parts=[{"type": "text", "text": "读取 mcp_servers.json 文件"}]
    )
    assert "info" in result or "parts" in result

    # 3. 获取消息历史
    messages = await client.get_messages(session_id=session["id"])
    assert isinstance(messages, list)

    # 4. 删除会话
    await client.delete_session(session_id=session["id"])
```

## 14. 部署方案

### 14.1 环境要求

| 组件      | 版本要求 | 说明                |
| --------- | -------- | ------------------- |
| Python    | ≥ 3.10   | 异步特性支持        |
| Node.js   | ≥ 18     | OpenCode 运行时依赖 |
| Bun       | ≥ 1.0    | OpenCode 源码运行时 |
| httpx     | ≥ 0.27.0 | 异步 HTTP 客户端    |
| LangChain | ≥ 0.3.0  | 工具注册            |

### 14.2 安装步骤

```bash
# 1. 确认 OpenCode 源码目录存在
ls "C:\Users\ZhuanZ\Desktop\opencode re\opencode - copy\package.json"

# 2. 确认 Bun 运行时已安装
bun --version

# 3. 安装 Python 依赖（已在 requirements.txt 中）
pip install -r requirements.txt

# 4. 创建配置文件
cat > data/opencode_config.json << 'EOF'
{
  "enabled": true,
  "port": 4096,
  "hostname": "127.0.0.1",
  "server_password": "your_password",
  "server_username": "opencode",
  "timeout": 30,
  "workspace_dir": "data",
  "opencode_source_dir": "C:\\Users\\ZhuanZ\\Desktop\\opencode re\\opencode - copy"
}
EOF

# 5. 设置环境变量
export OPENCODE_SERVER_PASSWORD=your_password

# 6. 启动服务
python src/main.py
```

## 15. 风险评估

### 15.1 技术风险

| 风险项              | 风险等级 | 缓解措施                |
| ------------------- | -------- | ----------------------- |
| OpenCode 服务器崩溃 | 中       | 健康检查 + 自动重启     |
| 端口冲突            | 低       | 动态端口分配            |
| 内存泄漏            | 中       | 会话池限制 + 定期清理   |
| API 兼容性          | 中       | 版本锁定 + 回归测试     |
| Windows 路径问题    | 低       | Path.resolve() 统一处理 |

### 15.2 安全风险

| 风险项         | 风险等级 | 缓解措施           |
| -------------- | -------- | ------------------ |
| 路径穿越攻击   | 高       | 白名单目录验证     |
| 危险命令执行   | 高       | 命令黑名单过滤     |
| 文件扩展名攻击 | 中       | 扩展名黑名单       |
| 文件大小炸弹   | 中       | 大小限制配置       |
| 权限提升       | 高       | 禁止 sudo/提权操作 |

### 15.3 运维风险

| 风险项         | 风险等级 | 缓解措施            |
| -------------- | -------- | ------------------- |
| 服务器启动失败 | 中       | 详细日志 + 错误提示 |
| 端口被占用     | 低       | 自动检测 + 报错     |
| 依赖缺失       | 中       | 启动前检查 + 提示   |
| 代理干扰       | 低       | 启动时清除代理变量  |

### 15.4 已知限制

1. **Windows 特定**: 二进制文件仅适用于 Windows x64
2. **单机部署**: 不支持分布式部署
3. **会话限制**: 默认最大 10 个并发会话
4. **文件大小**: 默认最大 100MB
5. **执行超时**: 默认 60 秒
