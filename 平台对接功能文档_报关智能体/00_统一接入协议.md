# 00 统一接入协议

## 功能定位

Agent V1 是平台侧唯一需要直接对接的智能体接口。平台只把用户消息、会话、附件引用、业务上下文传给本服务，本服务内部自行调用审单、法规检索、报告、Mock 报关、OCR、子智能体等能力。

## 基础地址

```http
/api/agent/v1
```

当前主要接口：

```http
POST /api/agent/v1/runs
GET  /api/agent/v1/runs/{run_id}/events
GET  /api/agent/v1/runs/{run_id}
POST /api/agent/v1/runs/{run_id}/cancel
GET  /api/agent/v1/outputs/{output_id}
GET  /api/agent/v1/outputs/{output_id}/content
GET  /api/agent/v1/capabilities
GET  /api/agent/v1/health
```

## 创建任务

```http
POST /api/agent/v1/runs
Content-Type: application/json
```

最小请求：

```json
{
  "request_id": "req-demo-001",
  "session": {
    "session_id": "platform-session-001",
    "user_id": "platform-user-001",
    "tenant_id": "tenant-001"
  },
  "message": {
    "role": "user",
    "content": "请审查这票报关数据"
  },
  "language": "zh",
  "options": {
    "intent": "auto",
    "response_mode": "stream",
    "include_tool_trace": true,
    "include_structured_result": true,
    "output_file_policy": "agent_temporary"
  }
}
```

返回：

```json
{
  "run_id": "run-xxx",
  "request_id": "req-demo-001",
  "status": "queued",
  "events_url": "/api/agent/v1/runs/run-xxx/events",
  "status_url": "/api/agent/v1/runs/run-xxx"
}
```

## intent 取值

| intent | 用途 |
| --- | --- |
| `auto` | 通用智能体入口，由模型选择工具 |
| `chat` | 普通报关咨询/工具编排 |
| `audit` | 固定审单能力 |
| `ocr` | 附件图片 OCR |
| `report` | 合规报告生成 |
| `declaration_query` | 报关单查询 |
| `regulation_search` | 法规检索 |
| `batch_audit` | 批量审单任务占位 |
| `full_review` | 综合审查演示链路 |
| `mock_import_declaration` | Mock 报关全链路 |

## SSE 消费

```http
GET /api/agent/v1/runs/{run_id}/events
Accept: text/event-stream
```

SSE 每条事件都有：

```json
{
  "schema_version": "1.0",
  "run_id": "run-xxx",
  "request_id": "req-demo-001",
  "session_id": "platform-session-001",
  "sequence": 3,
  "timestamp": "...",
  "event": "message_delta",
  "data": {}
}
```

平台需要根据 `event` 字段展示。

## 查询结果

```http
GET /api/agent/v1/runs/{run_id}
```

用于页面刷新、SSE 断线恢复、任务完成后查最终结果。

重点读取：

```text
status
final_answer
structured_result
outputs
warnings
error
usage
```

## 取消任务

```http
POST /api/agent/v1/runs/{run_id}/cancel
```

取消后 SSE 会收到：

```text
tool_finished(status=error)
agent_cancelled
```

平台不应继续显示“正在调用”。

## 平台最小实现

1. 创建 Run。
2. 保存 `run_id`。
3. 连接 `events_url`。
4. 按事件展示。
5. 下载 Output。
6. 支持取消。

## 注意事项

- `request_id` 由平台生成，并在租户内保持唯一；重复请求会被幂等处理。
- 平台前端必须忽略未知事件，不要因为新增 `subagent_*` 等事件报错。
- 不要把 API Key、模型密钥、服务器本地路径传入请求。
- 附件不要传 Base64，应通过平台文件中心提供临时 `download_url`。
