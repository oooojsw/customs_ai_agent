# 13 请求示例合集

本文件给平台后端直接复制调试。所有请求都使用：

```http
POST /api/agent/v1/runs
Content-Type: application/json
```

返回后连接：

```http
GET /api/agent/v1/runs/{run_id}/events
```

## 14. 取消任务

```http
POST /api/agent/v1/runs/{run_id}/cancel
```

返回：

```json
{
  "run_id": "run-xxx",
  "status": "cancelled",
  "cancellation_requested": true
}
```

取消后 SSE 正常会出现：

```text
tool_finished(status=error)
agent_cancelled
```
