# 08 输出文件与下载

## 功能定位

智能体不仅返回文字，还会产生报告、结构化 JSON、Excel、图片、归档等 Output。平台统一监听 `output_created` 事件即可。

## output_created 结构

```json
{
  "event": "output_created",
  "data": {
    "output": {
      "output_id": "out-xxx",
      "kind": "document",
      "format": "docx",
      "name": "报关智能体演示审单报告.docx",
      "mime_type": "application/vnd.openxmlformats-officedocument.wordprocessingml.document",
      "size": 248120,
      "sha256": "...",
      "source_tool": "report_generation",
      "platform_file_id": null,
      "preview_url": null,
      "download_url": null,
      "agent_output_url": "/api/agent/v1/outputs/out-xxx/content",
      "metadata": {
        "storage": "agent_temporary"
      },
      "created_at": "...",
      "expires_at": "..."
    }
  }
}
```

## kind 类型

| kind | 含义 |
| --- | --- |
| `document` | DOCX、PDF、TXT、Markdown |
| `image` | PNG、JPG、WebP |
| `spreadsheet` | XLSX、CSV |
| `structured_data` | JSON 结构化结果 |
| `table` | 前端可直接渲染表格 |
| `archive` | ZIP 等归档 |
| `citation_set` | 法规引用集合 |
| `validation_report` | 校验报告 |
| `template_definition` | 模板定义 |

## 下载方式

如果有：

```text
agent_output_url
```

平台可以直接请求：

```http
GET /api/agent/v1/outputs/{output_id}/content
```

如果未来平台提供文件中心，则智能体可上传到平台文件中心并返回：

```text
platform_file_id
download_url
preview_url
```

## output_file_policy

创建 Run 时可指定：

```json
{
  "options": {
    "output_file_policy": "agent_temporary"
  }
}
```

可选值：

| 值 | 含义 |
| --- | --- |
| `agent_temporary` | 本服务临时托管，返回 `agent_output_url` |
| `upload_to_platform` | 优先上传平台文件中心，失败时降级 |
| `none` | 不生成文件 Output |

## 平台展示建议

文件卡片展示：

```text
文件名
类型
大小
来源工具 source_tool
下载按钮
预览按钮，如果有 preview_url
过期时间，如果有 expires_at
```

## 当前边界

- 演示环境默认建议使用 `agent_temporary`。
- 临时文件有 TTL，平台需要长期保存时应下载后转存。
- 平台文件中心正式对接需要平台提供上传 URL、鉴权方式、返回字段。
