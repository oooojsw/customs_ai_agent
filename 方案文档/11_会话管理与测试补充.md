## 21. OpenCode 权限系统详细配置

### 21.1 权限配置 Schema

来自 `config.ts`，权限可以配置为以下级别：

```typescript
// 级别 1: 全局默认（字符串）
permission: "ask" | "allow" | "deny"

// 级别 2: 按工具配置（对象）
permission: {
  read: "allow",      // 读取文件 — 始终允许
  edit: "ask",        // 编辑文件 — 需要确认
  glob: "allow",      // 文件通配 — 始终允许
  grep: "allow",      // 文本搜索 — 始终允许
  list: "allow",      // 列出目录 — 始终允许
  bash: "ask",        // 执行命令 — 需要确认
  task: "allow",      // 任务执行 — 允许
  question: "ask",    // 提问用户 — 需要确认
  webfetch: "allow",  // 网页获取 — 允许
  websearch: "allow", // 网页搜索 — 允许
  lsp: "allow",       // LSP 功能 — 允许
  todowrite: "allow", // Todo 写入 — 允许
  todoread: "allow",  // Todo 读取 — 允许
}
```

### 21.2 headless 集成推荐配置

对于海关智能体 headless 集成，推荐以下配置：

```json
{
  "permission": {
    "read": "allow",
    "glob": "allow",
    "grep": "allow",
    "list": "allow",
    "edit": "deny",
    "write": "deny",
    "bash": "deny",
    "task": "allow",
    "question": "deny",
    "webfetch": "allow",
    "websearch": "allow"
  }
}
```

**说明**：

- `read/glob/grep/list` — 允许，这些是只读操作
- `edit/write/bash` — 禁止，避免 OpenCode 内部的 LLM 改写文件
- `task` — 允许，支持子任务执行

### 21.3 权限事件处理

当 OpenCode 需要权限确认时，会通过 SSE 发送 `permission.asked` 事件。headless 集成中可以通过 `/permission/:requestID/reply` 自动回复：

```python
async def auto_handle_permissions(opencode_client):
    """自动处理 OpenCode 权限请求"""
    while True:
        try:
            pending = await opencode_client._client.get("/permission")
            requests = pending.json()

            for req in requests:
                req_id = req.get("id")
                tool = req.get("tool", "")

                # 自动拒绝所有权限请求（因为我们禁用了编辑和执行）
                await opencode_client._client.post(
                    f"/permission/{req_id}/reply",
                    json={"reply": "reject", "message": "headless 模式下不支持权限确认"}
                )

        except Exception:
            pass

        await asyncio.sleep(1)
```

## 22. 多用户会话管理

### 22.1 会话隔离策略

每个用户请求应该使用独立的 OpenCode 会话：

```python
class UserSessionManager:
    """用户会话管理器"""

    def __init__(self, client, max_sessions: int = 20):
        self.client = client
        self.max_sessions = max_sessions
        self.user_sessions: Dict[str, str] = {}  # user_id -> session_id
        self._lock = asyncio.Lock()

    async def get_session(self, user_id: str, workspace_dir: str = "data") -> str:
        """获取用户的 OpenCode 会话"""
        async with self._lock:
            # 检查是否已有会话
            if user_id in self.user_sessions:
                session_id = self.user_sessions[user_id]
                # 验证会话是否还有效
                try:
                    await self.client.get_session(session_id)
                    return session_id
                except Exception:
                    del self.user_sessions[user_id]

            # 创建新会话
            result = await self.client.create_session(
                workspace_dir=workspace_dir,
                title=f"用户 {user_id} 的会话"
            )
            session_id = result["id"]
            self.user_sessions[user_id] = session_id

            # 清理过期会话
            if len(self.user_sessions) > self.max_sessions:
                oldest = next(iter(self.user_sessions))
                old_sid = self.user_sessions.pop(oldest)
                try:
                    await self.client.delete_session(old_sid)
                except Exception:
                    pass

            return session_id

    async def cleanup_user(self, user_id: str):
        """清理用户的会话"""
        if user_id in self.user_sessions:
            session_id = self.user_sessions.pop(user_id)
            try:
                await self.client.delete_session(session_id)
            except Exception:
                pass

    async def cleanup_all(self):
        """清理所有会话"""
        for session_id in list(self.user_sessions.values()):
            try:
                await self.client.delete_session(session_id)
            except Exception:
                pass
        self.user_sessions.clear()
```
