# 01 通用智能体对话

## 功能定位

通用智能体对话用于报关咨询、工具编排、自由问答和综合任务处理。平台侧可以把它作为“报关智能助手”入口。

## 推荐 intent

```json
{
  "options": {
    "intent": "auto"
  }
}
```

或明确：

```json
{
  "options": {
    "intent": "chat"
  }
}
```

## 请求示例

```json
{
  "request_id": "req-chat-001",
  "session": {
    "session_id": "session-chat-001",
    "user_id": "user-001",
    "tenant_id": "tenant-001"
  },
  "message": {
    "content": "进口全自动贴片机需要注意哪些申报风险？"
  },
  "options": {
    "intent": "auto",
    "response_mode": "stream",
    "include_tool_trace": true
  }
}
```

## 平台展示

至少展示：

```text
message_delta：智能体文字回答
tool_started：工具开始
tool_finished：工具结束
warning：非阻断警告
agent_completed：完成
agent_failed：失败
agent_cancelled：取消
```

如果智能体调用子智能体，例如 OpenCode，会额外出现：

```text
subagent_started
subagent_finished
```

平台可以先忽略 `subagent_*`，不影响主流程展示；如果要展示，可显示为“正在调用子智能体执行复杂任务”。

## 演示建议

用户输入：

```text
我准备进口一台全自动贴片机，品牌 Panasonic，型号 NPM-D3A，HS 编码 84798962，金额 150000 USD。帮我看看申报风险。
```

视频展示重点：

- 智能体能理解报关业务语言。
- 智能体会提示风险点，例如申报要素、价格、监管条件等。
- 平台能实时展示流式回答和工具调用状态。

## 当前边界

- `auto/chat` 是自由智能体入口，回答质量依赖当前模型和提示词。
- 如果平台希望固定流程、固定可复现结果，应使用 `audit`、`full_review` 或 `mock_import_declaration`。
