# 06 合规报告生成

## 功能定位

合规报告生成用于把报关数据、审单结论、法规依据整理成报告文件。平台可以展示报告生成过程，并提供下载。

## 推荐 intent

```json
{
  "options": {
    "intent": "report"
  }
}
```

## 请求示例

```json
{
  "request_id": "req-report-001",
  "session": {
    "session_id": "session-report-001",
    "user_id": "user-001",
    "tenant_id": "tenant-001"
  },
  "message": {
    "content": "请根据以下审单结果生成合规建议书"
  },
  "business_context": {
    "report_source": "货物名称：全自动贴片机\nHS编码：84798962\n风险：CIF成交方式下运费为零，建议补充实际运费数据。"
  },
  "options": {
    "intent": "report",
    "output_file_policy": "agent_temporary",
    "output_formats": ["docx"],
    "timeout_seconds": 1200
  }
}
```

## 平台展示

重点展示：

```text
tool_started: 生成合规建议书
status_changed: 报告生成阶段
tool_finished: 报告完成
output_created: DOCX 报告
message_delta: 报告已生成
```

## Output

报告文件通过：

```text
output_created.data.output
```

示例：

```json
{
  "kind": "document",
  "format": "docx",
  "name": "合规建议书.docx",
  "source_tool": "report_generation",
  "agent_output_url": "/api/agent/v1/outputs/out-xxx/content"
}
```

## 演示建议

视频里建议把报告生成放在最后：

1. 先审单或跑 Mock 报关。
2. 再点击“生成报告”或发起 `report`。
3. 平台展示报告文件卡片。
4. 点击下载 DOCX。

## 当前边界

- 当前主要生成 DOCX 演示文件。
- PDF、图片报告、正式模板样式可以后续扩展。
- 如果平台文件中心不可用，使用 `agent_output_url` 临时下载。
