# 10 演示视频候选场景

以下 5 个点适合给平台方挑选录制。建议选择 3 到 5 个组合，不要一次堆太多。

## 1. 平台统一入口调用智能体

### 演示价值

证明智能体已经集成在平台内，不需要打开本项目网页。

### 操作

平台页面输入：

```text
进口全自动贴片机需要注意哪些申报风险？
```

### 展示点

```text
POST /api/agent/v1/runs 创建任务
SSE 流式返回
message_delta 实时显示
tool_started/tool_finished 显示工具状态
```

## 2. 智能审单风险提示

### 演示价值

让观看者理解智能体能做报关风险检查。

### 推荐输入

```text
报关单号：TEST-005
货物名称：塑料圆珠笔
HS编码：96081000
数量：5000 支
单价：100.00 USD
总价：500,000.00 USD
原产国：越南
申报要素：1.品名：圆珠笔；2.品牌：无名；3.材质：塑料。
```

### 展示点

```text
价格异常
风险提示
审单结论
规则执行过程
```

## 3. Mock 报关全链路

### 演示价值

这是最完整的业务演示，能展示流程进度条和海关模拟回复。

### 推荐配置

```json
{
  "business_context": {
    "mock_case_id": "high_risk_inspection",
    "step_delay_ms": 800
  },
  "options": {
    "intent": "mock_import_declaration"
  }
}
```

### 展示点

```text
创建案件
加载单证
预审
提交海关
海关受理
海关审单
查验
征税
放行
结关
```

## 4. 报告生成与下载

### 演示价值

证明智能体能产出文件，而不只是聊天。

### 操作

使用 `full_review` 或 `report`。

### 展示点

```text
生成 DOCX 报告
output_created 文件卡片
点击下载
```

## 5. 附件/图片识别预留演示

### 演示价值

展示平台文件上传和多模态能力方向。

### 当前建议

如果 OCR 服务稳定，演示上传报关单图片并返回结构化结果。  
如果 OCR 服务不稳定，只演示平台附件输入协议和“多模态接口已预留”，不要承诺 PDF 稳定识别。

### 展示点

```text
平台上传图片
智能体下载附件
image_ocr 工具执行
structured_data Output
可选 XLSX Output
```

## 推荐视频组合

最稳组合：

```text
统一入口调用 -> 智能审单 -> Mock 报关全链路 -> 报告下载
```

如果多模态负责人已经准备好样例：

```text
统一入口调用 -> 图片 OCR -> 智能审单 -> Mock 报关全链路 -> 报告下载
```
