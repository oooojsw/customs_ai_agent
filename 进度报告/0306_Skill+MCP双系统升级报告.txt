## 架构设计要点

### 1. 异步初始化
- MCP 服务器启动必须是异步的，避免阻塞 FastAPI
- 使用 `await agent.initialize_mcp_tools()` 延迟加载

### 2. 生命周期管理
- 使用 `AsyncExitStack` 解决异步上下文管理器的生命周期问题
- 确保 MCP 连接在整个 Agent 生命周期内保持活跃

### 3. 错误隔离
- MCP 加载失败不影响本地 Skill 系统
- 宽松模式：单个 MCP 服务器失败不影响其他服务器

### 4. 沙盒安全
- 文件系统 MCP 限定在 `./data` 目录内
- 防止越权访问系统核心文件
