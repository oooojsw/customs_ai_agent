# 05 法规检索

## 功能定位

法规检索用于根据报关问题、审单风险或商品信息，从知识库中整理法规依据和引用片段。

## 推荐 intent

```json
{
  "options": {
    "intent": "regulation_search"
  }
}
```

## 请求示例

```json
{
  "request_id": "req-regulation-001",
  "session": {
    "session_id": "session-regulation-001",
    "user_id": "user-001",
    "tenant_id": "tenant-001"
  },
  "message": {
    "content": "进口集成电路申报要素和价格审核需要关注哪些法规依据？"
  },
  "business_context": {
    "regulation_query": "进口集成电路申报要素和价格审核"
  },
  "options": {
    "intent": "regulation_search",
    "include_tool_trace": true,
    "include_structured_result": true
  }
}
```

## 平台展示

重点展示：

```text
tool_started: 检索法规依据
tool_finished: 已整理若干条依据
output_created: citation_set
message_delta: 文字总结
```

## Output

法规结果可能通过 `output_created` 返回：

```json
{
  "output": {
    "kind": "citation_set",
    "format": "json",
    "name": "法规依据",
    "source_tool": "regulation_search",
    "data": [
      {
        "source": "mock-regulation/price-review",
        "snippet": "价格审核应关注数量、单价、总价及贸易单证之间的逻辑关系。",
        "score": 0.9
      }
    ]
  }
}
```

## 演示建议

可以在审单后追加演示：

```text
请给出这些风险点对应的法规依据。
```

视频展示重点：

- 平台不仅展示结论，还能展示“依据来源”。
- 法规引用可以作为报告生成材料。

## 当前边界

- 检索结果依赖当前知识库内容。
- 演示模式可能返回 Mock citation。
- 正式法规库、引用页码、法规版本管理需要后续知识库维护。
