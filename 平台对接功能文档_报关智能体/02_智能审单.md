# 02 智能审单

## 功能定位

智能审单用于对报关数据做风险检查，包括字段完整性、金额逻辑、HS 编码、申报要素、价格异常、单证一致性等。

## 推荐 intent

```json
{
  "options": {
    "intent": "audit"
  }
}
```

## 请求示例

```json
{
  "request_id": "req-audit-001",
  "session": {
    "session_id": "session-audit-001",
    "user_id": "user-001",
    "tenant_id": "tenant-001"
  },
  "message": {
    "content": "报关单号：TEST-005\n货物名称：塑料圆珠笔\nHS编码：96081000\n数量：5000 支\n单价：100.00 USD\n总价：500,000.00 USD\n原产国：越南\n申报要素：1.品名：圆珠笔；2.品牌：无名；3.材质：塑料。"
  },
  "business_context": {
    "declaration_text": "报关单号：TEST-005\n货物名称：塑料圆珠笔\nHS编码：96081000\n数量：5000 支\n单价：100.00 USD\n总价：500,000.00 USD\n原产国：越南\n申报要素：1.品名：圆珠笔；2.品牌：无名；3.材质：塑料。"
  },
  "options": {
    "intent": "audit",
    "include_tool_trace": true,
    "include_structured_result": true
  }
}
```

## SSE 展示

平台应展示：

```text
status_changed：开始审单
tool_started：某条规则开始
tool_finished：某条规则完成
message_delta：审单总结
agent_completed：完成
```

## 最终结果

查询 `GET /runs/{run_id}` 后重点读取：

```text
final_answer
structured_result.findings
warnings
```

## 演示建议

推荐演示“异常价格风险”：

```text
塑料圆珠笔，数量 5000 支，单价 100 USD，总价 500000 USD。
```

视频展示重点：

- 平台输入结构化或半结构化报关文本。
- 智能体指出价格异常、交易合理性风险。
- 平台展示风险结论和规则执行过程。

## 当前边界

- 当前审单是辅助判断，不代表真实海关审核结论。
- 审单结果应标注“仅供辅助参考，需人工复核”。
- 若输入信息不足，智能体可能只能给出风险提示，不能形成完整结论。
